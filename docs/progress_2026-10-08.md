
## 사용자가 확인·결정할 것

1. **붙여넣기 실동작**: 자동화 세션에서는 SendInput이 거부돼 검증하지 못했다. 메모장을 열고 `python -m shell` 실행 → ctrl+alt+a 누른 채 말하고 떼기 → 텍스트가 들어가는지, 클립보드가 원래대로 복원되는지 확인.
2. **단축키 감지**: `python -m shell.hotkeys --test --seconds 5` 실행 중 ctrl+alt+a/b를 눌러 press/release가 찍히는지.
3. **마이크**: config `input_device = "2"`(내장 마이크 배열). 엔진이 켜져 있는 동안 마이크가 계속 열려 있다(프리롤용). Windows 마이크 사용 표시가 켜진 상태가 정상.
4. **오보정 게이트 한계**: 문맥 판단이 문장 단위라, 함정 문장에 개발 단어가 섞이면 바뀔 수 있다. 본 녹음 평가에서 수치로 확인 후 ±N어절 창으로 좁힐지 결정.
5. **230문장 녹음**: `python -m evaltools.record --sentences data/sentences/sentences_v1.tsv`. 이후 run_eval·stream_eval로 1-0 기준표.
